# Privacy Policy — Hermes Health Sync

_Last updated: October 8, 2026_

**Hermes Health Sync** is a personal, single-user tool. It is not offered to the public, and
the only person who uses it is the owner of this repository.

## What it accesses
With the owner's own consent, it reads the owner's own data from the Google Health API
using **read-only** permissions: activity and fitness, health metrics and measurements,
sleep, profile, and device settings (for the paired device's last sync time).

## How the data is used
The data is summarised into daily totals (for example steps, sleep, resting heart rate)
and stored on a private server controlled by the owner, for the owner's personal health
tracking. Nothing is written back to Google.

## Sharing
The data is **never** sold, shared with, or disclosed to any third party, and is not used
for advertising or to train models.

## Storage and deletion
Access tokens are stored privately on the owner's server. Access can be revoked at any time
from the Google Account's "Third-party apps & services" page, and the stored data can be
deleted by the owner at any time.

## Google API Services User Data Policy
Use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

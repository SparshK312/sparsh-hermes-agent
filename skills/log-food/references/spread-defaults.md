# Spread / soft-topping default portions

Session note:
- For terse breakfast logs like "toast with garlic spread" or "bread + cream cheese", use a thin default spread portion when the amount is omitted.
- Default confirmation amount: ~20g for a soft spread/topping, shown explicitly in the confirm block as `~20g`.
- Keep the meal confirmation compact and allow the user to correct the amount before vault write.

Examples:
- 2 slices sourdough + garlic & herb cheese spread, ~20g
- 1 bagel + cream cheese, ~20g
- toast + butter, ~10–15g if clearly just a light smear

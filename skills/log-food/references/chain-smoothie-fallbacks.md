# Chain smoothie / nutrition-page fallback notes

Use this when a branded smoothie or chain drink has an official product page but the nutrition display is awkward.

## Pattern
- Prefer the **official chain page** when the product is identifiable.
- If the page only exposes nutrition in **per-100g** form, look for the same product in a chain nutrition guide, search snippet, or product listing that gives a **per-serving / per-sku** macro line.
- Use the **most directly matching serving size** you can verify for the exact item ordered.
- Keep add-ons / boosters as separate line items when they were explicitly chosen.
- If a booster has no meaningful calories/macros, log it as a zero-macro add-on only if the menu clearly identifies it; otherwise omit and note the ambiguity.

## Example observed
- **Booster Juice Nuttin' Better**: official page identified the product and ingredient list; a search result snippet exposed the regular **710 mL** serving macros, which is a better fit for logging than trying to convert the per-100g baseline by hand.
